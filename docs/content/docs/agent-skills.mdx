Agent Messenger includes an `agent-messenger` entry skill for selecting a platform and acting identity, resolving conversations, verifying delivery, and handling reply follow-ups. It routes to the existing platform skills, so agents do not need every platform's instructions in context.

## What Are Agent Skills?

When you give an AI agent access to a CLI tool, it needs to know:

- What commands are available
- How to format arguments
- What output to expect
- Best practices and common patterns

Agent Skills provide this knowledge in a structured format that AI agents can understand.

## Installation

### For AI agents

When asked to use Agent Messenger, install the entry skill in the current project, unless it is already installed:

```bash
npx -y skills add agent-messenger/agent-messenger --skill agent-messenger --yes
```

Read its `SKILL.md` at the path reported by the installer. To target a specific supported agent, append `--agent codex`, for example. Do not add `--global` unless requested.

The entry skill explains how to install and read only the required platform skill, for example:

```bash
npx -y skills add agent-messenger/agent-messenger --skill agent-slackbot --yes
```

Skill installation does not install or authenticate the CLI, grant permission to send messages, or start listeners. Install the CLI through the [quick start](/docs/quick-start) if necessary, and preserve the user's account and approval constraints.

### Skills CLI (interactive selection)

To choose platform skills interactively instead:

```bash
npx -y skills add agent-messenger/agent-messenger
```

Installation paths depend on the selected agent and scope. See the installer's output and [skills.sh](https://skills.sh/) for details.

### Claude Code

Add Agent Messenger skills to Claude Code:

```bash
# From terminal
claude plugin marketplace add agent-messenger/agent-messenger
claude plugin install agent-messenger
```

Or from within Claude Code:

```
/plugin marketplace add agent-messenger/agent-messenger
/plugin install agent-messenger
```

## How It Works

Once installed and read, the skills guide your agent to:

1. **Discover the CLI** - Check the installed version's commands and flags
2. **Select the acting identity** - Reuse the intended user or bot account; set up authentication only when authorized
3. **Resolve the destination** - Identify the recipient, conversation, and original thread
4. **Perform the requested operation** - Send, read, reply, or react within the task's scope
5. **Verify the result** - Retain the receipt, reconcile uncertain writes, and verify a reply-receiving mechanism before promising automatic follow-up

## Example Interaction

With Agent Messenger skills installed, you can ask your AI agent:

> "Send a message to #general saying the build passed"

The agent will:

1. Select the intended Slack user account and verify its identity
2. Resolve the exact `general` channel and confirm the installed send syntax
3. Execute the authorized `agent-slack message send general "The build passed"`
4. Confirm the returned delivery result, without treating it as proof the recipient read it
